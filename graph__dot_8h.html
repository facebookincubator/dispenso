template<typename G >
void dispenso::graphsToDot ( const char * filename,
const G & graph,
const std::unordered_map< uintptr_t, std::string > * nodeNames )

Write graph to filename in Graphviz DOT format, for example to render with dot -Tsvg. Each subgraph after the first is drawn as a cluster, completed nodes are coloured differently from incomplete ones, and for a BiPropGraph edges within a bidirectional-propagation set are drawn with open arrowheads.

Parameters
filenamepath of the file to write; it is overwritten.
graphthe graph to write.
nodeNamesoptional labels, keyed by the address of a node or subgraph cast to uintptr_t. Nodes and subgraphs without an entry are labelled by their index.
